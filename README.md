# Muneeb Ihsan Portfolio

Static GitHub Pages portfolio for Muneeb Ihsan — Unity Game Developer.

## Deploy

1. Create a public repository named `MuneebIhsan.github.io`
2. Upload all files from this folder to the repository root
3. Open **Settings → Pages**
4. Under **Build and deployment**, choose **Deploy from a branch**
5. Select `main` and `/ (root)`
6. Save

Your site will be available at:

`https://muneebihsan.github.io`

## Customize Projects

Open `index.html` and edit the **Selected Work** cards with your real project names, screenshots and store links when available.
